# 個人作品集

純 HTML、CSS 與少量 JavaScript 的單頁個人網站，無需安裝套件或建置工具，可直接用 Git 版控並部署到 GitHub Pages。

## 個人化

編輯 `index.html`，搜尋並替換「你的名字」、「你的所在地」、「專案名稱」與 `hello@example.com`；再更新自我介紹、專案說明、年份與圖片。圖片目前使用 Unsplash 遠端圖片，請替換成自己的作品圖或照片。

## 發布到 GitHub Pages

1. 將此資料夾建立為 GitHub repository，提交並推送 `index.html` 與 `README.md`。
2. 在 repository 開啟 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，再按 **Save**。
4. 稍候片刻，GitHub Pages 會提供網站網址。之後推送到 `main` 的更新會自動發布。

`index.html` 放在 repository 根目錄，因此不需要額外建置步驟或工作流程。
